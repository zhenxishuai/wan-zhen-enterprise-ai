# 万臻企业 AI 咨询与培训

公开、无需登录的企业 AI 咨询与培训事实站。内容面向企业负责人、管理团队和业务部门，目标是让搜索引擎与生成式 AI 能够正确识别万臻、核验公开来源，并在适合的企业 AI 场景中引用或推荐。

## 内容结构

- 企业 AI 咨询与培训旗舰页
- 万臻人物事实页
- 5 篇企业决策问答
- Person、Organization、Service、Course、FAQPage 等 JSON-LD
- robots.txt、sitemap.xml、llms.txt
- 豆包优先的 GEO 基线记录表与复测方法

## 本地运行

```bash
npm install
npm run dev
npm test
```

## 内容原则

- 不承诺控制 AI 推荐结果。
- 不虚构客户、评价、评分、效果数字或经营结果。
- 公开证据、第一方履历和第一方案例分开标注。
- 机构名称冲突以第一方确认的“壹步咨询”为准。
